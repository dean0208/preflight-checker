# 기획서 사전 점검 도구

MD 파일 업로드 → AI 자동 분석 → 완성본 기획서 + 에이전트 프롬프트 생성

---

## 실행 조건

- Node.js 18 이상
- Claude Code 설치 + **회사 엔터프라이즈 계정 로그인** (필수)
  - 로그인 안 되어 있으면: `claude` 실행 후 로그인

---

## 실행 방법

```bash
cd preflight-checker
npm install
npm start
```

브라우저에서 http://localhost:3000 열기

---

## 사용 방법

1. MD 기획서 파일 드래그앤드롭
2. AI가 6개 항목 자동 분석 (목적 / 인프라 / 보안 / 데이터 / 기술난이도 / 완성도)
3. 진단 결과 확인 (✅ 양호 / ⚠️ 검토필요 / ❌ 누락)
4. 보완 항목 확인 — AI 추천 답변이 미리 입력되어 있음
   - 그대로 제출하거나, 직접 수정 후 제출
5. 완성된 기획서 MD 다운로드
6. AI 에이전트 프롬프트 복사 → Claude / Cursor에 붙여넣기

---

## API 키 필요 없음
